So why does my portfolio look like a video game menu?

The honest answer is that I played Persona 3 Reload and it got me hooked. The game is so much fun, and everything about how it looks is striking, bold and creative. Even the pause menu has more personality than most websites I have seen. And the music! I kept the soundtrack playing long after I put the game down.

I had been meaning to build a portfolio website for a while. I kept putting it off because every design I sketched felt like the same site everyone else has. A plain hero, a grid of cards, a contact form at the bottom. Nothing wrong with that, but nothing fun about it either.

At some point it clicked. If a game can make opening a menu feel exciting, then a website can make reading about my projects feel exciting too. The Persona 3 Reload look was the right choice for me: deep underwater blues, sharp diagonal shapes, and text that leans like it is in a hurry to get somewhere.
